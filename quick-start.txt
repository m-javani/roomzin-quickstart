================================================================================
                         ROOMZIN QUICK-START GUIDE
================================================================================

1. START THE CLUSTER
   -----------------
   make start SHARDS=1 ZONES=1 LEVEL=full RZPROXY=true

   ⏱️ Wait ~15 seconds for all services to become healthy.

2. TEST IT
   --------
   # Set a property
   curl -X POST http://localhost:8777/api \
     -H "Content-Type: application/json" \
     -d @sample-queries/01-setprop.json

   # Search availability
   curl -X POST http://localhost:8777/api \
     -H "Content-Type: application/json" \
     -d @sample-queries/03-search.json

   # Check cluster health
   make health

3. SERVICE ENDPOINTS
   ------------------
   RzProxy (HTTP):  http://localhost:8777
   RzID:            http://localhost:8081
   RzPoint:         http://localhost:9090
   Edge Router:     localhost:9200

4. QUICK COMMANDS
   ---------------
   make start     - Launch the cluster
   make stop      - Stop the cluster
   make clean     - Clean up everything

5. SAMPLE QUERIES
   ---------------
   All queries in sample-queries/ are pre-configured with property IDs
   and dates that match the generated test data.

   Available:
   - 01-setprop.json      Create a property
   - 02-setroompkg.json   Add room availability
   - 03-search.json       Search for inventory
